# Soccer-Predictor
A machine learning-powered web application that predicts the European Top 5 Leagues (Serie-A, Premier League, LaLiga, Ligue1, Bundesliga) standings using historical match data and machine learning.

What It Does
This project analyzes 5 seasons of Premier League matches and predicts:

League champion
Top 4 teams (Champions League spots)
Europa League qualifiers
Relegation candidates

To run locally:
Clone or download the respository 
Make sure to install the requirements in requirements.txt
Run the main.py file
Select which league you want to predict
View the predictions
